# skeleton-crew

Skills that make your AI agents brief you like a professional staff.

## Install

```bash
npx skills add mpiv-ai/skeleton-crew -g
```

Pick the skills and the agents you want. Works with Claude Code, Codex, Cursor and the other agents the `skills` installer supports.

## Skills

| Skill | What it does |
| --- | --- |
| `bluf` | Bottom line up front. Every answer starts with the answer. Every decision comes with everything you need to make it. |

From MPIV Labs.
