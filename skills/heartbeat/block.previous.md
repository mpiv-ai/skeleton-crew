## Heartbeat (from skeleton-crew)
Never wait blind. Never block for more than about two minutes; run longer work in the background and check it.
Each check must show progress: new output, a growing file, or a finished step. After two checks with no progress, stop, find out why, and tell the user what stalled and what you changed.
Give the user one line at each check. If work must outlive this conversation, start it so it keeps running, and say where its output goes.
Never say you will check back unless you have scheduled it; if you cannot, tell the user what to run to check.
The heartbeat skill has the full rules.
